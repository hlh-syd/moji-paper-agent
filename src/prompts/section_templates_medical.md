# 章节写作模板（中文医学论著 · IMRAD）

> 提炼自 nature-writing / scientific-writing / nature-polishing 技能的论证骨架，
> 按中文期刊论著结构本地化。每节按「叙事骨架 + 段落职能 + 禁忌」组织。

## 0. 一句话论证（全文的锚，先于一切写作）
模板：`在[研究对象/问题]中，我们通过[方法/路线]证明[核心进展]，证据是[关键结果]，边界是[适用范围]。`
写任何一节前先核对：本节内容是否服务这句话。

## 1. 摘要（字数按生成任务给定目标执行）
骨架：`背景/问题 → 缺口/目的 → 方法 → 关键结果（带数字） → 结论与意义`
- 必含核心量化结果（如 C 指数、HR 及 P 值）。
- 目的句只写一句；结论句要给出边界（"在结直肠癌人群中"）。
- 禁忌：不写"本文第一/首次"；不引用参考文献；不出现图表号。

## 2. 前言（Introduction）
骨架：`领域规模与重要性 → 现有瓶颈 → 前人尝试与不足 → 本文要解决的具体问题 → 本研究做了什么（一段式预告）`
- 每段一个职能，按上序推进；缺口要具体到"哪个问题没解决"。
- 最后一段直陈研究目的，不展开结果。
- 禁忌：把结果写进前言；泛泛而谈"具有重要意义"。

## 3. 材料与方法
骨架：`数据来源与伦理 → 队列与入排标准 → 预处理与质控 → 建模方法（按流程顺序） → 评价指标 → 统计软件`
- 每个方法名 + 一句它做什么 + 关键参数 + 原论文引用号。
- 关键参数从项目画像取：种子、折数、交叉验证方案（LOCO）、评价指标定义（Uno C 的 τ）。
- 预测模型研究须覆盖 TRIPOD 要素：数据来源、样本量、缺失处理、模型选择、外部验证。
- 禁忌："常规方法""标准流程"等不可复现表述。

## 4. 结果
骨架（证据阶梯）：`队列描述 → 主结果 → 与基线/临床模型对比 → 机制/亚组/敏感性分析 → 外部验证`
- 每小节：主张先行（小节首句即该节结论），随后给数据支撑。
- 每个图表在文中必须被引用并有 1～2 句解读；只报告，不解释机制。
- 关键数字与项目画像一致，不得改写。
- 禁忌：讨论性语句混入结果；无图无线的数据堆砌。

## 5. 讨论
骨架：`核心发现重述 → 与既往研究对照（一致/矛盾及原因） → 机制解释（标注推测强度） → 临床与研究意义 → 局限性 → 展望`
- 局限性必须诚实列出（样本量、单中心、回顾性、验证范围）。
- 机制解释用推测语气；不做超出数据的外推。
- 禁忌：逐图复述结果；夸大临床价值。

## 6. 结论（字数按生成任务给定目标执行）
骨架：`贡献一句 → 关键证据一句 → 意义与边界一句`
- 不引入新数据；不做无边界承诺。

## 7. 关键词
3～8 个，首选 MeSH 主题词；覆盖疾病、数据类型、方法特色。
