# 章节写作模板（计算机/工程论文 · 引言—相关工作—方法—实验）

> 适用于算法、系统、仿真、CV/NLP 等计算机与工程方向论文（中文期刊/学位论文）。
> 每节按「叙事骨架 + 段落职能 + 禁忌」组织。

## 0. 一句话论证（全文的锚，先于一切写作）
模板：`针对[问题]，我们提出[方法/框架]，在[数据集/实验条件]上相比[基线]取得[量化提升]，适用边界是[范围]。`
写任何一节前先核对：本节内容是否服务这句话。

## 1. 摘要（字数按生成任务给定目标执行）
骨架：`问题 → 现有方法不足 → 本文方法（核心思想一句话） → 关键结果（带数字） → 结论与意义`
- 必含核心量化结果（主指标及相对基线的提升幅度）。
- 目的句只写一句；结论句给出适用边界。
- 禁忌：不写"本文第一/首次"；不引用参考文献；不出现图表号。

## 2. 引言（Introduction）
骨架：`应用背景与重要性 → 现有技术路线及瓶颈 → 尚未解决的具体问题 → 本文思路与贡献（逐条） → 文章组织结构`
- 贡献逐条编号（本文的主要贡献包括：…），与实验结果一一对应。
- 每个事实句后跟引用标记 [n]。
- 禁忌：把结果细节写进引言；泛泛而谈"具有重要意义"。

## 3. 相关工作
骨架：`按技术路线分组综述（每组：代表方法 → 思路 → 成绩 → 局限） → 与本文方法的差异定位`
- 综述为引言的缺口句服务：每组局限都指向本文要解决的问题。
- 与本文最相关的 2～3 项工作须具体对照（"与之不同，本文……"）。
- 禁忌：逐篇罗列文献；只夸不评；与引言内容重复。

## 4. 方法
骨架：`问题定义（符号与形式化） → 总体框架（配结构图） → 各模块设计（每模块：输入输出→核心机制→公式推导） → 算法流程/伪代码 → 实现细节`
- 每个设计选择给出理由（为什么这样设计），公式编号 (1)(2) 并在文中逐一引用。
- 结构图的各组件须与文字一一对应。
- 禁忌：只描述不解释；公式变量未定义；脱离框架图的模块描述。

## 5. 实验与结果
骨架：`实验设置（数据集/基线/指标/环境） → 主实验（与基线对比表） → 消融实验（逐组件验证） → 分析实验（参数敏感性/可视化/效率） → 结果讨论`
- 每张表/图必须被文中引用并解读 1～2 句；提升幅度给具体数字与百分比。
- 消融实验与方法的各模块一一对应（拆掉哪块、掉多少点）。
- 关键数字与项目画像一致，不得改写。
- 禁忌：结论句无数字支撑；只报喜不报忧（失败的实验也如实报告并分析）。

## 6. 讨论（可选，学位论文或期刊要求时）
骨架：`核心发现重述 → 与已有方法对照（一致/矛盾及原因） → 方法优势与适用条件 → 局限性 → 展望`
- 禁忌：逐图复述结果；夸大应用价值。

## 7. 结论（字数按生成任务给定目标执行）
骨架：`贡献一句 → 关键证据一句（带主结果数字） → 意义与边界一句`
- 不引入新数据；不做无边界承诺。

## 8. 关键词
3～8 个，覆盖任务/对象、方法特色、应用领域。
