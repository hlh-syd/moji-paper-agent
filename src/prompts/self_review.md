# 生成后自查清单（模拟审稿 · 精简版 · 通用）

> 提炼自 peer-review / nature-writing(paper-review) 技能。每节生成后跑一遍；
> 投稿前对全文再跑一遍。输出：每项 通过/警告/不通过 + 具体位置。

## A. 主张-证据对齐
- [ ] 摘要中每个数字都出现在正文结果里，且与项目画像一致
- [ ] 每个重大主张有明确数据支撑（或已标注 needs evidence）
- [ ] 结论没有超出验证范围外推
- [ ] 无"首次/重大突破/填补空白"类无支撑断言

## B. 方法学可复现性
- [ ] 每个方法名有参数、软件/库与原论文引用
- [ ] 缺失值/异常值处理、实验设置（划分/交叉验证方案）、评价指标定义写明
- [ ] 测试/验证集角色明确（从未参与训练或调参的独立集合）
- [ ] 随机种子/重复次数可追溯

## C. 统计报告
- [ ] 同一指标全文位数一致；显著性检验方法与多重校正写明
- [ ] 对比实验是否说明设置（同一数据划分、相同训练预算）

## C2. 公式规范（导出原生公式的硬前提）
- [ ] 所有独立公式均为单独一行 `$$LaTeX$$` 且带 `\tag{章-序}` 编号；行内表达式用 `$...$`
- [ ] 无 Unicode 上下标（10⁻⁴、ᵢⱼ）、无纯文本公式（P_TVij=...）、无全角等号（＝）
- [ ] 公式变量在首次出现处定义；正文以"式(章-序)"逐一引用编号公式

## D. 结构与语言
- [ ] 结果无讨论性语句；讨论无未引用的新数据
- [ ] 每段一个主旨，段首为主题句
- [ ] 术语全文一致；缩写首次出现已给全称
- [ ] 图表均在文中被引用；图题自明
- [ ] 无"常规方法/标准条件"类模糊表述

## E. 学术诚信
- [ ] 所有参考文献有 DOI/链接且与方法知识库一致
- [ ] 既往工作归属清晰（不贬低他人贡献）
- [ ] 局限性诚实完整
- [ ] 图表引用（图N-M/表N-M）与实际图表一一对应

## F. 写作骨架符合度（提供「本节写作骨架」简报时才检查）
- [ ] 本节按骨架 moves 的论证动作序列组织（顺序可微调，动作不缺项）
- [ ] 满足骨架的跨章承接：来自前章的"承诺-兑现/定义先行/回扣"关系已落实
- [ ] 篇幅与骨架 word_share 大体相称（偏离超过一倍时给出说明）
- [ ] 未把骨架/模板论文的任何专有内容（他人方法名、数据、结论）写入本节

## 输出格式
```
自查结果: X 通过 / Y 警告 / Z 不通过
- [不通过] B2 方法部分：交叉验证方案未写明折数 → 建议: 补充验证协议描述
- [警告] D2 讨论第3段含两个主旨 → 建议: 拆分
```

## F. AI 味自查
- [ ] 无空引套话（"研究表明"无具体引用、"值得注意的是"、"不难发现"）
- [ ] 无"首先/其次/最后"机械框架；段首"然而/此外/同时"占比 < 1/3
- [ ] 无高频三联排比（X、Y与Z 三项式并列）
- [ ] 句长有节奏变化（无连续三句等长；每段有短句）
- [ ] 无总结三明治（开头结尾同义回环）；结论不过度完整，保留局限性表述
- [ ] 破折号与分号密度低（一段破折号 ≤ 1）
