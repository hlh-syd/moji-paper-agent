# 章节写作模板（通用科研论文 · IMRAD）

> 适用于自然科学/工程技术各学科的中文期刊论著与学位论文。
> 每节按「叙事骨架 + 段落职能 + 禁忌」组织。

## 0. 一句话论证（全文的锚，先于一切写作）
模板：`在[研究对象/问题]中，我们通过[方法/路线]证明[核心进展]，证据是[关键结果]，边界是[适用范围]。`
写任何一节前先核对：本节内容是否服务这句话。

## 1. 摘要（字数按生成任务给定目标执行）
骨架：`背景/问题 → 缺口/目的 → 方法 → 关键结果（带数字） → 结论与意义`
- 必含核心量化结果（主指标数值及对比基线）。
- 目的句只写一句；结论句要给出适用边界。
- 禁忌：不写"本文第一/首次"；不引用参考文献；不出现图表号。

## 2. 前言（Introduction）
骨架：`领域背景与重要性 → 现有方法/技术的瓶颈 → 前人尝试与不足 → 本文要解决的具体问题 → 本研究做了什么（一段式预告）`
- 每段一个职能，按上序推进；缺口要具体到"哪个问题没解决"。
- 最后一段直陈研究目的，不展开结果。
- 禁忌：把结果写进前言；泛泛而谈"具有重要意义"。

## 3. 材料与方法
骨架：`数据/样本来源 → 预处理与质控 → 方法/模型（按流程顺序） → 评价指标 → 工具与环境`
- 每个方法名 + 一句它做什么 + 关键参数 + 原论文引用号。
- 关键参数从项目画像取：随机种子、实验设置、评价指标定义。
- 禁忌："常规方法""标准流程"等不可复现表述。

## 4. 结果
骨架（证据阶梯）：`数据/样本描述 → 主结果 → 与基线/已有方法对比 → 敏感性/稳健性分析 → 验证`
- 每小节：主张先行（小节首句即该节结论），随后给数据支撑。
- 每个图表在文中必须被引用并有 1～2 句解读；只报告，不解释原因。
- 关键数字与项目画像一致，不得改写。
- 禁忌：讨论性语句混入结果；无图无线的结论句。

## 5. 讨论
骨架：`核心发现重述 → 与既往研究对照（一致/矛盾及原因） → 机制或原因解释（标注推测强度） → 应用与研究意义 → 局限性 → 展望`
- 局限性必须诚实列出（数据规模、验证范围、假设条件）。
- 机制/原因解释用推测语气；不做超出数据的外推。
- 禁忌：逐图复述结果；夸大应用价值。

## 6. 结论（字数按生成任务给定目标执行）
骨架：`贡献一句 → 关键证据一句 → 意义与边界一句`
- 不引入新数据；不做无边界承诺。

## 7. 关键词
3～8 个，覆盖研究对象、数据类型、方法特色。
