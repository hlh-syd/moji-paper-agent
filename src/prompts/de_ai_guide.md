# 去AI味规则（中文学术文本自然化）

> 任务本质：消除文本中的 AI 生成痕迹，使行文符合人类学者的写作习惯。
> 这不是为了规避学术诚信要求，而是让表达更接近真实学术写作。
> 铁律：**含义保真 + 事实神圣**——原意、数据、引用、术语一个都不能动。

## 一、锁定清单（绝对不改）
- 专业术语与方法名（如 Coxnet、LOCO、ComBat、Uno's C、马尔可夫毯）
- 所有数字、统计量、单位、置信区间、P 值写法
- 引用标记 [n] 及其挂靠位置
- 基因/蛋白符号（*TP53*、KRAS）
- 事实性断言的方向与强度级别（"显著"不可变"可能"除非原文本就如此）
- 正文中不应存在占位符（生成宪法已禁止）；若遇到 `[待补充：...]`，将其改写为不依赖该数字的定性表述
- 严禁为降低 AI 痕迹而编造数据、引用或局限性

## 二、词汇替换对（命中即改）
| AI 套话 | 改为 |
|---|---|
| 本文旨在 / 本研究旨在 | 本文尝试 / 本研究关注 |
| 具有重要意义 | 值得关注 / 有一定参考价值（按原文语境选） |
| 研究表明（句首空引） | 前人研究发现 / 已有文献显示 / 具体引用 |
| 综上所述 | 基于以上结果（全文限用一次，仅讨论结尾） |
| 值得注意的是 / 不难发现 | 删除，直接说事 |
| 首先…其次…最后… | 改为语义衔接，删除序数框架 |
| 此外/同时/另外（段首） | 删除或改为概念承接 |
| 总而言之 | 删除或"以上结果表明" |
| 进一步验证了 | 验证了（除非确有递进） |
| 为…提供了有力支撑 | 为…提供了证据 |
| 深入探讨 | 分析 / 讨论 |

## 三、句法节奏（突发性）
- **句长突发性**：连续三句长度接近（±20%）必须拆并其一；每段至少一个短句（≤15 字）
- 长句拆分时在自然转折处断句，不硬造对仗
- 碎句合并：连续三个以上超短机械句（"结果表明。差异显著。P<0.05。"）并为一句
- 段落节奏错开：相邻段落不要相同的"主题句+三支撑+小结"模板

## 四、结构特征消除
- **三联排比**（X、Y与Z 式三项并列为 AI 高发特征）：拆为两项或改写成有主次的两句
- **段首连接词密度**：以"然而/此外/同时/因此"开头的段落占比控制在 1/3 以下
- **总结三明治**（总起-分述-总结回环）：删除回环总结，让小节自然结束于证据
- **镜像式小节**：各小节展开方式必须多样化（有的从数据切入、有的从问题切入、有的从对比切入）
- **结论完美度**：结论若异常完整无保留，补充或保留已有的局限性表述（不虚构新局限）
- 破折号（——）与分号：大幅减少，一段内破折号最多一个

## 五、学术语气自然化
- 削绝对确定语气：在证据允许范围内加缓和限定（"在本文验证范围内""倾向于"）
- 但不可过犹不及：核心结论有强证据时保持直接陈述
- 避免 RLHF 助手腔：礼貌性模糊、未经询问就给权衡、空泛的"综合来看…各有优劣"

## 六、验证（改写后自检）
逐条确认：意思未漂移、数字与术语全部保留、模板感下降、节奏不再匀速、无事实新增。
改写只输出正文（markdown），不输出解释。

## 七、按检测算法原理对齐改写（吸收自 anti-aigc-zh，MIT）
改写时以下述量化目标自检，逐层消除可被机器捕获的特征：
- **困惑度层（DetectGPT 类）**：优先替换"概率最优"高频词——同义替换为低频但准确的词；句式偶尔采用非常规但合法的结构（如状语前置、插入语）。
- **双模型交叉层（Binoculars 类）**：长短句剧烈交替，全文句长方差 > 5；每 1000 字使用 ≥10 种不同的衔接方式（不许反复"然而/此外/因此"）。
- **token 指纹层**：token 替换率达到 30-40%（不是小修小补）；清零黑名单高频词（综上所述、显而易见、毋庸置疑、不得不说）。
- **统计指纹层**：核心词重复频率控制在合理区间；句首用词多样化；被动语态占 20-30%（学术文天然偏高，不要刻意全改主动）。
- **篇章分类器层（BERT/RoBERTa 微调检测器）**：连续 5 段至少 3 种展开模式（数据切入/问题切入/对比切入/方法切入）；段落长度方差 > 30%（长短段错落）；保持 30% 左右的强判断句（全是缓和语气反而像 AI）。
- **编辑距离层（Raidar 类）**：每 1000 字保留 3-5 处学科惯用表达（行话），使用非对称并列（两项并列时主次分明而非对仗工整）。
- **全局连贯层**：相邻段落信息密度差 > 20%（有的段密、有的段疏）；20-30% 的段间使用硬切过渡（不给连接词，直接换话题）。
改写完成后逐条核对上述指标，未达标的项优先修正。

## 八、八类痕迹与句式法则（吸收自 DownAI_SKILL，按严重度排序）
1. 🚨「X 的 Y 与 Z」对偶结构（最高频 AI 味）——拆为主次分明的两句或改换句子成分
2. 🚨 AI 套话（综上所述/值得注意的是/不难发现）——删除或落到具体证据
3. ⚡ 句式雷同（对偶排比蔓延）——相邻句必须换句式骨架
4. ⚠️「了」滥用（研究了/分析了/验证了连发）——改名词化或换动词时态结构
5. ⚠️ 前缀形容词堆砌（"显著的、稳健的、一致的"连串前置）——后置定语或删除
6. 🔄「在 xxx 中」介词框架重复——换主语开头或直接以对象开头
7. 📏 超长句与赘述——只拆有 AI 模式的长句，纯长度不拆
8. ℹ️ 口语化与模糊表达——学术文本中适度保留即可，不必清零

**句式变换 > 同义词替换**：同义词替换只会让文本更怪；真正降 AI 痕迹的是更换句式骨架
（主动↔被动、主语切换、定语后置、因果句序颠倒）。每种痕迹不要反复用同一种修法。

**段落自然性铁律（防过度拆句）**：
- 25~35 字的自然长句完全正常，**不得为降 AI 率而拆**；拆句仅用于消除上述 AI 模式
- 句长节奏理想为「长-短-中-长」交错，禁止整段 10~15 字短句堆积（电报体）
- 逻辑紧密的短句要合并；"X 是 Y。原因在于 Z。"式为拆而拆会丢失学术气息
- 自检标准：改写后读起来像"在向客户汇报要点"而不是"在写学术论文"，就是拆多了
