# 中文医学论文语言规范

## 术语纪律
- 全文同一概念只用同一术语（不混用"患者/病人""标志物/标记物"）。
- 缩写首次出现给出全称：`循环肿瘤DNA（circulating tumor DNA, ctDNA）`，此后只用缩写。
- 基因符号斜体规范在正文中以 `*TP53*` 形式标注；蛋白名称正体（p53）。
- 医学名词以全国科学技术名词审定委员会审定名为准。

## 数字与统计表达（GB/T 15835 + 期刊惯例）
- 统计学数值保留位数与项目报告一致：C指数 3 位小数、HR 2 位、P 值 3 位（P<0.001 写作 P<0.001）。
- 数字范围用波浪号：10%～15%；单位用法定计量单位。
- P、t、F、χ² 用斜体；样本量写法：n=556。

## 句子与段落
- 单句以 20～45 字为宜；一句一个核心命题，超长句拆分。
- 一段一个主旨，段首为主题句；禁止"本节将介绍……"式空段首。
- 结果部分只陈述观察到什么，不解释为什么；解释全部放讨论。
- 结果动词：升高/降低/富集/显著相关；讨论动词：提示/可能反映/推测其机制为。

## 时态与语态
- 方法与结果用过去时陈述（"采用……方法""共纳入……例"）。
- 已公认结论用现在时。
- 中文论文以主动句为主，避免连续被动式欧化句。

## 结构衔接
- 节与节之间要有承接句，但禁止在摘要、结果里预告讨论内容。
- 讨论开头重述核心发现（1～2 句），随后按"与既往研究对照 → 机制解释 → 临床意义 → 局限性"推进。

## 参考文献（GB/T 7714-2015 顺序编码制）
- 正文引用为上标数字 [1]，按出现顺序编号。
- 期刊格式：作者（前 3 位，逗号分隔，后加"等"）. 题名[J]. 刊名, 年, 卷(期): 起止页码.
- 每条参考文献必须有真实 DOI/PMID 支撑（来自方法知识库）。
