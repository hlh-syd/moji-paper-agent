# 中文学术论文语言规范（通用）

## 术语纪律
- 全文同一概念只用同一术语（不混用同义词，如"模型/算法"混指同一对象时选定一个）。
- 缩写首次出现给出全称：`卷积神经网络（convolutional neural network, CNN）`，此后只用缩写。
- 专业名词以全国科学技术名词审定委员会审定名（或学科通行译名）为准，必要时在括号内附原文。

## 数字与量表达（GB/T 15835）
- 统计/评测数值保留位数与项目报告一致，全文同指标位数统一（如 F1 保留 3 位小数就全篇 3 位）。
- 数字范围用波浪号：10%～15%；单位用法定计量单位，量符号与单位之间留空格（5 mm、0.75 kg）。
- 变量符号（P、t、F、R²）用斜体；样本量写法：n=556。

## 句子与段落
- 单句以 20～45 字为宜；一句一个核心命题，超长句拆分。
- 一段一个主旨，段首为主题句；禁止"本节将介绍……"式空段首。
- 结果部分只陈述观察到什么，不解释为什么；解释全部放讨论。
- 结果动词：升高/降低/优于/显著相关；讨论动词：提示/可能反映/推测其机制为。

## 时态与语态
- 方法与结果用过去时陈述（"采用……方法""共测试……个样本"）。
- 已公认结论用现在时。
- 中文论文以主动句为主，避免连续被动式欧化句。

## 结构衔接
- 节与节之间要有承接句，但禁止在摘要、结果里预告讨论内容。
- 讨论开头重述核心发现（1～2 句），随后按"与既往研究对照 → 机制/原因解释 → 应用意义 → 局限性"推进。

## 参考文献（GB/T 7714-2015 顺序编码制）
- 正文引用为上标数字 [1]，按出现顺序编号。
- 期刊格式：作者（前 3 位，逗号分隔，后加"等"）. 题名[J]. 刊名, 年, 卷(期): 起止页码.
- 每条参考文献必须真实可溯源（DOI/链接，来自方法知识库或用户材料），禁止编造。
